# My Game Profile

This repo holds an encrypted backup of a Game Profile from everythingyouneed.dev. Without the password nothing in vault/ can be read.

The public profile (public/profile.json) only contains games, numbers and matches from the game APIs. View it at https://everythingyouneed.dev/tools/game-profile/?u=klaasvm

Restore it on https://everythingyouneed.dev/tools/game-profile/ via Settings, Fetch from GitHub. Don't edit anything here by hand: that can break the backup.
